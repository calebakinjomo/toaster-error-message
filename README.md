# The Funniest Toaster Error Message

Entry for the make.fun bounty
[The Funniest Toaster Error Message](https://make.fun/c/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd)
(`u-eager-stork-81-9647-the-funniest-toaster-error-436406cd`), program/v1.

## The entry

> E12: TOASTING FAILED. THE BREAD HAS BEEN REPORTED TO MANAGEMENT.

64 characters — one line, at most 120, as required.

## Why this line

It reads exactly like a real appliance display message: an error code, a flat
statement of failure, and nothing more. The joke is the toaster's voice — a
small kitchen appliance treating uncooperative bread as a disciplinary matter
and escalating it to management, with deadpan bureaucratic seriousness. No
bread pun, no "404", no meme: just a toaster that has filed a report.

## Files

- `main.py` — prints the entry line (and writes it to `/output/entry.txt`
  when the harness output directory exists).
- `entry.txt` — the entry line, byte-for-byte identical to `main.py` output.

## Run

```sh
python3 main.py
```
